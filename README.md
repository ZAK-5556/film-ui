# Film UI

React-застосунок для роботи з фільмами з REST-сервісу
[film-service](https://github.com/ZAK-5556/film-service) (Завдання Блоку 3).
Предметна область та REST API взято із Завдань 1–2: фільми (`Film`) і їхні режисери (`Director`).
Проєкт створено на основі шаблону [ui-base-app-next](https://github.com/IvanovAAKh/ui-base-app-next).

## Сторінки

| Сторінка                       | URL                  |
|--------------------------------|----------------------|
| Список фільмів                 | `/films`             |
| Детальна інформація фільму     | `/film/{id}`         |
| Створення фільму               | `/film/new`          |

Список фільмів також відкривається з меню (іконка ☰ у шапці) і з кнопки на головній сторінці.

### Список фільмів

- Для кожного фільму показано назву, режисера та рік.
- Під час наведення курсора на фільм праворуч з'являється кнопка видалення (на мобільних пристроях
  вона видима завжди). Видалення підтверджується в діалозі. Якщо видалити не вдалося, діалог
  залишається відкритим і показує помилку. Після видалення фільм зникає зі списку і з'являється
  повідомлення, що зникає саме через кілька секунд.
- Натискання на фільм відкриває його сторінку в тому ж вікні.
- Кнопка «Додати фільм» відкриває сторінку створення фільму.
- Кнопка «Фільтр» відкриває діалог з трьома полями: режисер, рік і країна. Фільтрує `film-service`
  (`POST /api/film/_list`). Активні фільтри показано над списком, кожен можна прибрати окремо.
- Пагінація: по 5 фільмів на сторінці.
- Фільтр і номер сторінки зберігаються в URL (`?directorId=1&country=USA&page=2`), тому вони не
  скидаються після перезавантаження сторінки.

### Детальна інформація фільму

- Відкривається в режимі перегляду. Кнопка-олівець праворуч угорі вмикає режим редагування.
- У режимі редагування є кнопки «Зберегти» і «Скасувати». «Скасувати» повертає режим перегляду зі
  старими значеннями.
- Поля перевіряються під час натискання «Зберегти»: невалідні поля підсвічуються з поясненням, і запит
  на сервер не надсилається. Обмеження такі самі, як у `film-service`:

  | Поле     | Валідація                                              |
  |----------|--------------------------------------------------------|
  | Назва    | обов'язкове, до 200 символів                           |
  | Режисер  | обов'язкове, вибирається зі списку режисерів сервісу   |
  | Рік      | обов'язкове, ціле число від 1888 до 2100               |
  | Країна   | необов'язкове, до 100 символів                         |
  | Жанри    | необов'язкове, через кому, разом до 300 символів       |

  Якщо сервіс усе ж відхилить поле, його повідомлення показується під цим полем.
- Після успішного збереження сторінка повертається в режим перегляду з новими значеннями та показує
  повідомлення, що зникає саме. Якщо зберегти не вдалося, сторінка залишається в режимі редагування і
  показує помилку.
- Сторінка створення (`/film/new`) одразу відкривається в режимі редагування з порожніми полями та
  кнопками «Створити» і «Скасувати». «Скасувати» повертає до списку фільмів.
- Кнопка «Назад» повертає до списку з тими самими фільтром і сторінкою, що були до переходу.

Інтерфейс доступний українською та англійською (перемикач мови в шапці).

## Збирання і запуск

Потрібні **Node.js 18+** і запущений `film-service` із Завдання 2 на `http://localhost:8080`
(інструкція із запуску та імпорту тестових фільмів є в README того проєкту).

```bash
npm install
npm start
```

Застосунок відкривається на `http://localhost:3050/films`.

Скрипт `start` задає порт у синтаксисі Windows (`set PORT=3050`). На Linux/macOS порт задається так:
`PORT=3050 npm start`. Порт саме 3050, бо з цього адресу `film-service` дозволяє запити (CORS).

За бажанням можна скопіювати `.env_example` у `.env`. Тоді всі сторінки отримають префікс `/theGame`
(наприклад, `http://localhost:3050/theGame/films`).

### Запити до film-service

Адресу сервісу задано в `src/config/index.js` (`FILMS_SERVICE`).

| Запит                       | Де використовується                        |
|-----------------------------|--------------------------------------------|
| `POST /api/film/_list`      | список фільмів: фільтр і пагінація         |
| `GET /api/film/{id}`        | перегляд фільму                            |
| `POST /api/film`            | створення фільму                           |
| `PUT /api/film/{id}`        | збереження змін                            |
| `DELETE /api/film/{id}`     | видалення фільму                           |
| `GET /api/director`         | вибір режисера у фільтрі та у формі фільму |

### Тести

Unit-тести (Jest) перевіряють валідацію форми фільму та роботу з параметрами списку в URL:

```bash
npm test -- --watchAll=false
```

## Структура змін відносно шаблону

```
src
├── config/index.js                   адреса film-service
├── constants/films.js                NEW_FILM_ID — id у URL сторінки створення фільму
├── misc/requests/films.js            запити до /api/film
├── misc/requests/directors.js        запит до /api/director
├── misc/hooks/useDirectors.js        завантаження списку режисерів
├── misc/components/DirectorSelect.jsx  вибір режисера у фільтрі та у формі фільму
├── components/                       Alert, Chip, Pagination, Snackbar та іконки (обгортки над MUI, як у шаблоні)
├── pageProviders/                    FilmList, FilmDetails
└── pages
    ├── filmList
    │   ├── containers/FilmList.jsx             сторінка списку: завантаження, фільтр, пагінація
    │   ├── components/FilmListItem.jsx         рядок списку з кнопкою видалення
    │   ├── components/FilmFilterDialog.jsx     діалог фільтра
    │   ├── components/DeleteFilmDialog.jsx     підтвердження і видалення фільму
    │   └── utils/listParams.js                 фільтр і сторінка ⇄ параметри URL
    └── filmDetails
        ├── containers/FilmDetails.jsx          режими перегляду, редагування і створення
        ├── components/FilmView.jsx             поля фільму в режимі перегляду
        ├── components/FilmForm.jsx             поля фільму в режимі редагування
        └── utils/filmForm.js                   валідація і перетворення значень форми
```

Невеликі зміни в коді шаблону:

- `misc/requests/index.js` — обробник помилок axios більше не падає, коли сервіс повертає помилку не
  масивом (у `film-service` це `{"message", "fieldErrors"}`) або коли відповіді немає зовсім;
- `components/TextField` може бути випадним списком (`select`), а `components/MenuItem` передає далі
  атрибути, які додає список (`role`, `aria-selected` тощо);
- `app/components/LeftNavBar.jsx` — пункт меню «Фільми», доступний усім користувачам;
- `package.json` — `typescript@4` у `devDependencies`: без нього npm встановлює TypeScript 7, з яким
  ESLint з `react-scripts` не може перевірити тести.
